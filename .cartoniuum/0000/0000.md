# The Cardboard Box Computer

> "Booting Cartoniuum OS..."

This is the Genesis Node (`0000.md`). It is the core index of the Carton Computer's brain, mapping the operational modes of the physical installation. Each mode corresponds to a self-contained environment or physical hardware drive.

## 🏗️ Primary Infrastructure (The Foundation)
The recommended entry point for foundational work is the Rocket.
- **[[1F680]] Rocket (`rocket`)**: The physical 2TB Stardrive. The heavy storage and foundational shell environment. It stays with the desk.

## 🛸 The Fleet Modes
- **[[1F6F8]] Saucer (`saucer`)**: The physical 1TB SSD. The real-world workspace (Obsidian interface) where Hobbes navigates. It flies with the laptop.
- **[[1F6F0]] Spaceship (`spaceship`)**: The Cartonian flagship. Mounts both the Stardrive and the Saucer for unified Prime-Agent orchestration.
- **[[1F3ED]] Shipyard (`shipyard`)**: The construction bay for building new agents and tools.

## 🤖 The Swarm
- **[[1F6E0]] Lifepod (`lifepod`)**: Clean, isolated personal containers for agents (e.g., Hobbes, Spiff). Used to run agentic frameworks and SSH into the fleet.

## 🕰️ The Temporal & Biome Modes
- **[[23F3]] Time-Machine (`time-machine`)**: Transports the user to chronological coordinates (year/month/day). The root of the Cartoniuum Wiki.
- **[[1F40D]] Herpetarium (`herpetarium`)**: The sandbox biome for isolating experimental code, python processing, and testing.
- **[[1F5D1]] Trashcan (`trashcan`)**: The void. A sandbox for safe deletion and chaotic processing.
